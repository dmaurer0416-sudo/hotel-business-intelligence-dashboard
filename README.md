# 🏨 Hotel Business Intelligence Dashboard

A full-stack Business Intelligence project designed to help hotel owners, restaurant managers, and property management teams make data-driven decisions.

Using SQL, this project analyzes revenue, labor costs, occupancy, food costs, payroll, and profitability to identify why certain properties outperform others.

---

## Business Problem

Many hospitality businesses know **which property is making the most money**, but not **why**.

This dashboard answers questions such as:

- Which hotel generates the most revenue?
- Which department is most profitable?
- Which manager has the best-performing property?
- Where can labor costs be reduced?
- Which restaurant items generate the highest profit?
- How does occupancy affect revenue?
- Which days of the week generate the highest sales?
